# cs2114-project2-group60

The folder for our LinkedChain<T> music player project

## Reflection:

In our specification some things that changed is that we added more methods for song and audio. For song i added more getters so that it would be easier to access title and author. For audio I had to make changes for play and add some exceptions.

## How to compile and run the program and the tests:

After putting the classes in the src folder, put the .wav files in the parent folder. Then run the Main class as a java app and have fun. Tests can be ran by manually testing inside of the program due to how the program is all about the buttons interacting with classes.
